# scrcpy-flow

> 把手机上的重复操作，变成一张可以反复运行的“流程画布”。

scrcpy-flow 是一个面向安卓手机的自动化工具。它不需要你写死坐标脚本：你只要在关键页面截一张图，程序运行时会把手机当前画面和这些截图比对，判断“现在在哪个页面”，然后执行你为这个页面配置的动作（点击、滑动、输入、启动应用等）。

它同时接入了本地大模型（Ollama）和云端大模型（任意兼容 OpenAI 接口的服务），在图片匹配失败时让人工智能看屏接管，也可以用一句话直接生成整条流程甚至整个多区块项目。

---

## 功能特性

### 自动化执行

- **图片匹配驱动**：截图 + 整体向量粗筛 + 检测重点区域细算，页面改版、分辨率变化都能按比例适配。
- **可视化流程画布**：拖拽节点、连线、缩放画布；节点检查器里可视化框选检测重点和点击位置。
- **多种动作**：点击、滑动、按键、输入文本、启动应用、等待、人工智能决策、极速连滑/连点。
- **失败处理链**：重试 → 人工智能接管 → 人工记住的动作 → 静态保底步骤，一层层兜底。
- **区块项目**：把多条流程按顺序串成项目，也可以用 Python 编排（`if`、`while`、变量）。
- **历史与复盘**：每次运行记录会话、每一步的匹配分数、动作和截图，随时回看。

### 加速

- **三档加速**：普通 / 快速 / 极速。快速把步骤间等待缩到五分之一，极速直接跳过等待。
- **极速连滑 / 连点**：用 Android 自带的 monkey 一次注入成千上万次触摸，实测 **100 次约 1 秒（约 100 次/秒）**，200 次约 122 次/秒。参数（次数、起终点、时长）都能在检查器里编辑，起终点相同就是连点。

### 人工智能

- **本地模型**：接本机 Ollama，不联网、免费。支持人工智能决策节点、失败接管、候选节点重排、一句话生成流程。
- **云端模型**：底部「AI 助手（云端 API）」面板，内置 DeepSeek / OpenAI / 通义千问 / 本地 LM Studio / Ollama 兼容服务预设，填地址和密钥即可用。
- **三种后端**：本地 / 云端 / 自动（云端优先，失败回退本地）。
- **AI 自动创建项目**：「AI 生成流程 / 项目」对话框可以直接生成 1~4 个区块的完整项目，自动建流程、节点、顺序编排脚本。

### 人工介入

- 运行中随时点「人工选择」：点击屏幕任意位置、按手机按键、打开应用、滑动、输入文字、等待。
- 可勾选 **记住这个选择**：动作会变成流程画布里的「人工步骤」节点，下次匹配失败时自动作为保底动作，节点可编辑、可删除。
- 可勾选 **检测是否完成**：动作后截图比对，不达标可以重新人工选择，或让 AI 托管。

### 专业工具（专业版）

- 批量多设备运行。
- 智能定位（控件树 / OCR）。
- 录制回放。

## 环境要求

- Python 3.11 或更高版本（源码运行需要）。
- 安卓手机，开启「开发者选项 → USB 调试」。
- 安卓调试桥（Android Debug Bridge，`adb`）和 `scrcpy`：
  - **Windows**：把 scrcpy 发布包解压到 `tools\windows\` 下（程序会自动寻找），或安装后加入系统环境变量。
  - **macOS**：`brew install android-platform-tools scrcpy`
  - **Linux**：`sudo apt install adb scrcpy`（不同发行版包名略有差异）

> 出于仓库体积考虑，本仓库不包含 adb 与 scrcpy 的二进制文件；它们来自 scrcpy 官方发布包，遵循 Apache-2.0 许可。

## 快速开始

### 1. 安装依赖

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
pip install -r requirements-ui2.txt   # 图形界面需要
```

可选依赖：

```bash
pip install -r requirements-vision.txt   # 图像增强
pip install -r requirements-pro.txt      # 专业工具（OCR、录制）
pip install -r requirements-clip.txt     # CLIP 语义向量（较大，需 PyTorch）
```

### 2. 启动

```bash
python main.py
```

Windows 用户也可以直接双击 `run.bat`（会优先使用 `.venv` 虚拟环境）。

### 3. 连接手机

1. 手机打开「开发者选项 → USB 调试」。
2. 数据线连接电脑，手机上点「允许调试」。
3. 程序「运行」页的设备下拉框里选择你的手机；没有的话点「刷新设备」。

### 4. 做第一条流程

1. 左侧「工作区」右键新建流程。
2. 在「流程画布」里点「添加节点」，用 scrcpy 画面或 adb 截图。
3. 在节点检查器里框选「检测重点」、点选「点击位置」。
4. 给第一个节点勾选「入口」，最后一个节点勾选「结束」。
5. 回到「运行」页，选择这条流程，点「开始运行」。

更详细的建图教程见 [`docs/recipes.md`](docs/recipes.md)。

## 人工智能配置

### 本地模型（推荐先试）

1. 安装 [Ollama](https://ollama.com/)，启动服务。
2. 拉一个能看图的模型：

```bash
ollama pull qwen3.5:4b
```

3. 打开程序底部「AI 助手（本地 Ollama）」面板，点「刷新」确认状态。
4. 在「AI 设置」里勾选启用，模型留空会自动挑选。

### 云端模型

1. 打开底部「AI 助手（云端 API）」面板。
2. 「快速配置」里选服务商（DeepSeek / OpenAI / 通义千问 / 本地 LM Studio / Ollama 兼容）。
3. 填写 API Key，点「保存设置」→「测试连接」。
4. 「AI 后端」选「自动」或「云端 API」。

> 云端模式会把截图发给你配置的服务商，敏感页面请使用本地模型。
> 密钥只保存在本机数据目录的 `cloud.json`，不会上传到本项目。

## 加速与极速连滑

「运行」页的「加速」有三档：

| 档位 | 效果 |
|---|---|
| 普通 | 按原始等待时间执行，最稳 |
| 快速 | 所有等待缩短到五分之一 |
| 极速 | 跳过所有等待，重试次数降到 1 次 |

滑动节点想要“一秒滑几十次”，在节点检查器里选动作「极速连滑/连点（100+ 次/秒）」：

| 参数 | 说明 |
|---|---|
| 次数 | 一次注入多少次，建议 100 以上 |
| 起点 x / y | 相对屏幕比例（0~1） |
| 终点 x / y | 和起点相同就是连点 |
| 每次时长 | 每次手势持续毫秒数 |

> 实测（Android 11 / 1080×2400）：100 次约 0.95~1.05 秒，200 次约 1.64 秒，300 次约 2.2 秒。手机需要解锁并停留在目标页面。

## 命令行

不打开窗口也能用：

```bash
python -m scflow --list-devices           # 列出安卓设备
python -m scflow --list-flows             # 列出流程
python -m scflow --headless "每日点餐"     # 无界面运行流程或项目
python -m scflow --ai-status              # 检查本地模型状态
python -m scflow --ai-task "打开设置查看电池电量"   # 不建流程，直接让 AI 执行
python -m scflow --dry-run --headless "测试流程"    # 模拟运行，不真正点击
```

常用参数：`--serial` 指定设备、`--steps` 最大步数、`--data-dir` 指定数据目录、`--classic` 使用经典界面。

## 数据目录

程序第一次运行会在项目旁边生成 `data/`：

```
data/
├── scflow.db          SQLite 数据库（流程、节点、项目、运行记录）
├── images/            节点截图与素材
├── screenshots/       每次运行的步骤截图
├── ollama.json        本地模型设置
└── cloud.json         云端接口设置
```

升级或迁移时直接复制整个 `data/` 目录即可。也可以用界面里的「工程导出」把整个工程打包成一个文件。

> 发布/开源时请勿把 `data/` 一起提交，里面有你的截图和密钥。仓库的 `.gitignore` 已经忽略了它。

## 常见问题

**Q：程序找不到 adb / scrcpy？**
把 scrcpy 官方发布包解压到 `tools/windows/`（Windows），或安装到系统 PATH；也可以用环境变量 `SCFLOW_ADB`、`SCFLOW_SCRCPY` 指定路径。

**Q：点开始运行没反应？**
确认手机在线（`python -m scflow --list-devices`）、手机已解锁、开发者选项里的 USB 调试已授权。

**Q：总是“未匹配”？**
先看「历史」里的步骤截图和候选分数。分数在 0.5~0.8 说明像但不够像：降低阈值、加检测重点、重新截一张更干净的图；分数很低说明缺节点。

**Q：加速后容易点错？**
极速模式会跳过等待，页面还没渲染完就执行下一步。换成「快速」或「普通」，或者给节点加 `post_wait`。

**Q：极速连滑没反应？**
手机必须解锁并停在可滚动页面；锁屏时 monkey 注入不到事件。次数太少时平均速度会被启动开销拉低，建议 100 次以上。

**Q：本地模型回答很慢或只回“思考过程”？**
换小模型（如 `qwen3.5:4b`），在「AI 设置」里关闭“先思考”；或降低截图最长边。

**Q：云端接口报 401 / 404？**
检查 Key 是否正确、Base URL 是否包含 `/v1`、模型名是否是该服务商支持的模型。

**Q：能操作多台手机吗？**
专业版支持批量多设备；普通模式一次运行一台。

**Q：支持 iOS 吗？**
不支持，本项目基于安卓调试桥。
