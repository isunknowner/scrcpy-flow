# 现代工作区

使用 **PySide6（Qt）** 重写了界面，经典 Tkinter 界面仍可用 `--classic` 打开。

## 布局

- **左侧「工作区」dock**：项目 / 流程树，双击打开。
- **中央标签页**：区块编排、流程画布、运行、历史、相似度编辑；专业版额外显示「专业工具」。
- **右侧「属性 / 检测重点」dock**：状态图片缩放、取点击点、检测重点、点击对象、相对偏移点击、取相对点击点、相似度编辑入口、动作与连线。
- **底部「输出 / 控制台」dock**：所有面板状态与警告。
- 所有 dock 都可以拖动、停靠到其他边、双击标题浮动，或通过「视图」菜单变成独立窗口。
- 菜单额外提供「独立运行窗口」，可以把运行面板单独拉出来。

## 界面模式

- 工具栏右侧下拉框显示当前模式；菜单「视图 → 界面模式」和命令面板也可切换。
- **简洁版**：只保留项目区块顺序和运行，隐藏流程画布、历史、属性、控制台、Python/变量/设置。
- **普通版（默认）**：完整节点编辑、Python、变量、历史和控制台。
- **专业版**：普通版全部功能 +「专业工具」标签页。
- 模式保存在 `QSettings` 中，下次启动保持；旧版 `pro_mode` 设置会自动迁移到普通版/简洁版。

## 专业版工具

- **批量设备**：勾选多台设备，并发运行同一项目/流程，按设备输出日志，可停止全部。
- **智能定位**：读取 Android 控件树（uiautomator）或可选 OCR，测试点击，或把控件选择器/点击坐标写入当前节点。控件树定位失败会自动回退图片识别。
- **录制回放**：需要 `pynput`；在受控 scrcpy 窗口中操作手机，每次左键点击自动生成流程节点并串成流程。停止后可「编辑录制结果」，调整顺序、名称、点击位置、动作、等待和备注，支持删除、设入口或转到属性面板完整编辑。macOS 需要辅助功能权限，Linux 需要 X11。

## 相似度编辑

- 节点类型：侧重点检测节点（原图片/动作步骤合并）、侧重检测节点（原重点检测节点，W 固定为 1）、不检测步骤、IF 条件节点。
- 侧重点检测节点公式：`s = W1·MR + W2·MR非`。
- 侧重检测节点公式：`s = W·MR`，W 固定为 1。
- MR / MR非 由颜色、纹理、结构、边缘四类成分按权重合成。
- 入口：匹配阈值右侧按钮、右键匹配阈值、节点右键、流程画布「相似度编辑」模式。
- 预览区显示状态图片 + 颜色/纹理/结构/边缘成分图；MR/MR非/点击对象只保留权重设置。
- 单击预览图可放大；放大窗口的「选框不可视」勾选后显示不带选框的原始图片。
- 支持测试截图计算 s、点击对象成分编辑、返回流程画布；属性面板更改框选后预览会自动刷新。
- 新增「MR 成分锁定…」：每个成分可锁定；4 个成分合计超过 1 时自动扣减未锁定成分，若锁定成分已超过 1 或全部锁定则保存失败并提示。
- 新增 4 种 MR 成分匹配阈值（颜色/纹理/结构/边缘）；任一成分低于阈值时不执行动作，运行日志提示「动作相似度低」。

## 命令面板

`Ctrl+Shift+P` 打开，支持：

- 开始 / 停止运行
- 保存全部
- 新建项目 / 流程
- 运行示例项目
- 切换简洁版 / 普通版 / 专业版
- 浮动属性 / 工作区 / 控制台
- 刷新全部

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `F5` | 开始运行 |
| `Shift+F5` | 停止 |
| `Ctrl+S` | 保存全部 |
| `Ctrl+Shift+P` | 命令面板 |
| 滚轮 | 缩放流程画布 / 状态图片 |
| 中键拖动 | 平移画布 / 图片 |

## 部署

```bash
./install2.sh
./run2.sh
```

Windows 使用 `install2.bat` / `run2.bat`；macOS 使用 `install2.sh` / `run2.sh`。

macOS 需要先安装设备工具：

```bash
brew install android-platform-tools scrcpy
brew install cliclick   # 可选，scrcpy 窗口点击更稳定
```

依赖：`requirements-ui2.txt`，其中 `PySide6-Essentials` 是 Qt 界面，OpenCV 用于点击对象定位。

打包：

```bash
./build2_linux.sh
build2_windows.bat
```

## 与经典界面的关系

- 默认 `python -m scflow` 启动现代工作区；PySide6 不可用时自动回退经典界面。
- `python -m scflow --classic` 强制经典界面。
- 数据库、流程、项目、tools/ 完全共用，不需要迁移。
