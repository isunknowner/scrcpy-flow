# 区块编排（项目）

## 概念

- **流程（Flow）**：原来的一张图片状态图，包含节点、连线、检测重点、保底等。现在它同时是一个**区块**。
- **项目（Project）**：一组按顺序排列的区块，外加一段可选的 Python 编排脚本和变量。
- 一个项目里同一个流程只能出现一次；区块的 Python 变量名由流程名自动生成（中文可用），如 `首页`、`点餐`。
- 编辑模式顶部有两个页签：
  - **区块编排（项目）**：编辑区块顺序、Python、变量。
  - **流程画布（区块内部）**：编辑某个区块的节点、图片、点击点、检测重点和连线。

## 顺序模式

项目设置里选择「按区块顺序执行」时：

1. 按画布上的顺序逐个运行区块；
2. 每个区块用一次完整的运行引擎（截图、匹配、动作、保底、日志）；
3. 区块命中结束节点或达到最大步数视为完成；
4. 勾选「区块未完成时停止」时，某个区块出错会停止整个项目。

每个区块的日志仍然写入原来的流程会话，可在历史记录 → 流程会话里查看。

## Python 编排模式

选择「使用 Python 编排」并保存项目后，运行时会执行 Python 脚本。

### 区块名就是变量

每个区块自动得到一个变量名（显示在画布和右侧说明里）：

```python
if 首页():
    点餐()

while 选菜():
    if 确认():
        break
```

- `首页()` 会真正运行该区块，返回一个结果对象，可直接放在 `if` / `while` 里。
- 结果对象属性：
  - `.ok`：是否正常完成；
  - `.status`：`finished` / `max_steps` / `error` / `stopped`；
  - `.steps`、`.fallbacks`、`.session_id`、`.error`；
  - `.runs`（区块句柄上）表示本脚本调用次数。
- 变量 `首页` 本身在未运行时为 false；运行后可以用 `if 首页:` 判断上一次结果。

### 变量

在「变量」表里添加变量，例如：

| 变量名 | 值 |
| --- | --- |
| 次数 | 0 |
| 目标 | 3 |

脚本里可以直接当全局变量用（变量名必须是合法 Python 标识符），也可以使用 `变量` 字典：

```python
while 次数 < 目标:
    首页()
    次数 += 1
    变量["最后结果"] = "ok"
```

运行结束后，变量值会写入项目运行历史。

### 辅助函数

| 函数 | 作用 |
| --- | --- |
| `run_block("变量名")` | 按名字运行区块 |
| `set_var(name, value)` | 设置变量 |
| `get_var(name, default=None)` | 读取变量 |
| `log(message)` | 写入运行日志 |
| `sleep(seconds)` | 可被停止的等待 |
| `stop()` | 请求停止整个项目 |
| `launch_app(package, fresh=True)` | 启动应用；`fresh=True` 会先强制停止 |
| `key(name)` | 发送按键（如 `back`、`home`、`enter`） |
| `tap(x, y)` | 按屏幕像素坐标点击 |

### 示例：按条件选择

```python
if 首页():
    if 常点餐厅():
        pass
    else:
        新餐厅()
else:
    log("首页未命中，执行保底")
```

### 示例：循环直到成功

```python
尝试 = 0
while not 选菜() and 尝试 < 3:
    尝试 += 1
    sleep(1)
if 尝试 >= 3:
    stop()
```

## 安全与限制

- Python 环境只提供常用内置函数，不提供 `open` / `import` / `eval` / `exec`；这不是严格安全边界，请只运行自己写的脚本。
- `while True:` 如果完全不调用区块、不调用 `sleep`，无法被停止按钮中断；请避免纯 Python 死循环。
- `max_block_runs` 限制一个脚本最多调用多少次区块，防止 `while` 失控。
- `script_timeout` 会在区块调用、`sleep`、`log` 等位置检查超时。
- 单区块最大步数用于防止某个区块卡死。
- 撤销栈保存在内存中，关闭程序后清空；单个流程/项目最多保留 50 步。
- 「取消连接/下一步」按钮：先单击画布上的连线，或在节点右侧「下一步 / 偏好」列表选中连线，再点击即可删除。
